# Adaptive 2D AI Agent

An experimental project exploring how an autonomous AI agent can learn to interact with, navigate, and adapt to a dynamic 2D environment.

The project starts with fundamental reinforcement learning concepts and progressively develops the agent toward goal-based planning, memory, adaptation, and reusable skill discovery.

## Project Goals

- Build a 2D environment from scratch using Python and Pygame
- Understand and implement reinforcement learning from the fundamentals
- Train an agent using progressively more advanced RL techniques
- Introduce perception and limited environmental observations
- Add memory and experience-based decision making
- Implement goal-based planning and dynamic replanning
- Explore autonomous skill discovery and skill reuse
- Evaluate the agent's ability to generalize to unseen environments
